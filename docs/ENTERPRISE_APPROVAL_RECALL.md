# 企业级审批撤回与重提治理

`POST /api/enterprise/oa/approval-recall` 用于申请人发现材料、金额或业务内容错误时，在不破坏审计链的前提下撤回审批。

系统核对发起人权限和流程状态，禁止撤回已经付款、用印、发文或入账的流程；对已同步外部系统、已创建下游单据或已有审批意见的流程，生成补偿、通知和证据保留动作。接口返回 `RECALL / REVIEW / BLOCKED`、下一流程状态以及是否需要补偿事务。
