# 企业级公文发布治理

版权所有 © 2026 上海如静知华信息科技有限公司（[知华科技官网](https://www.zhuatech.cn/)）。

## 业务闭环

拟稿 → 会签 → 法务/制度审查 → 定密与范围复核 → 签章及编号 → 安全检查 → 正式发布 → 回执催办 → 归档。

## 发布门禁

- 待发布文本必须是冻结的最终版本，并完成密级、公开范围和收文对象复核。
- 法务审查、印章或电子签名、正式发文字号和附件安全扫描必须完成。
- 个人信息及敏感数据必须复核，归档分类与保管期限必须确定。
- 业务负责人必须批准，编制、审批和发布必须职责分离。
- 版本、会签、签发与发布必须形成完整审计证据链。

## 接口与决策

`POST /api/enterprise/oa/official-document-publication`

返回 `PUBLISH`、`REVIEW` 或 `BLOCKED`。电子签章、消息渠道和档案系统仅预留标准适配方式，部署方需自行配置。
